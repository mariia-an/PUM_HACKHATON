# ПоступИИ — ИИ-помощник для абитуриентов

Рекомендательная система вузов и образовательных программ на основе ЕГЭ и текстового описания интересов.  
**2-е место** на хакатоне ПУМ (Предуниверсарий МАИ) за 4 часа.

---

## Суть

Пользователь в диалоге с LLM-агентом называет предметы, баллы и свои карьерные предпочтения. Система фильтрует программы по проходным баллам, а затем ранжирует оставшиеся через **sentence‑transformers** (косинусное сходство между эмбеддингами описаний и запроса). 

Если запрос несерьёзный («хочу ничего не делать и зарабатывать») — система выдаёт адекватные запасные варианты (Синергия, киберспорт).
---

## Особенности

- Диалоговый сбор данных — агент уточняет, пока не получит всё необходимое.
- Фильтрация по баллам.
- Ранжирование по сходству с текстовым запросом.
- Масштабируемость — добавление новых программ без переобучения.
- Обработка краевых случаев (fallback).
